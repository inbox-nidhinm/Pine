# Niram redesign: decisions

Answers from the user, 6 October 2026. These win over anything else.

- Redesign Niram's interface the way Flip and Twine were made: the Flip Design System (Figma file `2XErpBfGuIGNU0DkL58Ute`, node 171:2055), the grain, PP Kyoto, the designer's icons, floating panels, no help text in the UI.
- Accent: magenta #E2387F, in place of Flip's green and Twine's blue.
- There is no Niram design: Claude lays it out the Flip way, shows the user, and the user corrects it.
- The menu bar dropdown becomes a custom floating panel (recent colours as swatches, Pick, Compare, Settings), drawn as Twine's menus are, in place of the system menu.
- Niram has its own git repository, pushed to `inbox-nidhinm/Niram`.
